**Para qué:** elegir el lenguaje visual según el **formato** del vídeo (cómo cuenta), no aplicar un estilo genérico a todo. Decisión del usuario, 07-11-2026: *no existe un único estilo de edición para todos los vídeos de Amin.*

**Relación con la biblioteca de estilos:** un formato dice *qué estructura y qué ritmo* tiene el vídeo; un estilo ([[8 BIBLIOTECA DE ESTILOS/00 Índice]]) dice *cómo se ve*. Un formato puede admitir varios estilos.

**Cómo se usa (antes de cualquier vídeo nuevo):**
1. Identificar el formato.
2. Consultar las referencias de ese formato (aquí).
3. Analizar el mensaje y el objetivo.
4. Proponer una dirección creativa específica.
5. Preguntar al usuario las decisiones relevantes.
6. Esperar su aprobación.

**Qué entra aquí:** referencias analizadas (hechos separados de interpretaciones), técnicas y decisiones **aprobadas** por el usuario. Lo que sale de un solo reel es una observación, no una regla.

**Estados de cada dato:**
- 👁 **observado** en una referencia (hecho);
- 💭 **interpretación** mía;
- ✅ **aprobado** por el usuario (con fecha);
- 🧪 **en prueba**.
