# Fichas de estilo

Una ficha JSON por cliente o marca. La lee `subtitulos.py` y el `montaje.json` copia su estilo.

| Ficha | Para quién | Estado |
|---|---|---|
| `amin.json` | La marca actual de Amin | Base: «Pobre vs rico v1» (aprobado el 22-10), más la dirección «natural y elegante» del 30-10. Probada en la muestra VIDEO2 |

## Reglas
- Las correcciones de un cliente actualizan **su** ficha y se apuntan en `../correcciones.md`.
- **Las fichas de Luis no se mezclan con la de Amin** (están en el traspaso, `02-reglas-y-numeros.md`):
  - ClienteA: azul y SF Pro. Era Amin con Luis; ya no es su marca.
  - ClienteE: naranja y Sequel Sans.
  - ClienteN: rojo y Futura Condensed.
- **Cliente nuevo:** copiar `amin.json` como plantilla. Hay que cambiar:
  - colores, letras y claves;
  - encuadre y música.
  - Anotar de dónde sale cada valor (aprobado, medido o «a ojo»).
